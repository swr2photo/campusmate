# CampusMate mobile design skills — Expo SDK 58

Two independent but complementary Claude Code Skills:

- `.claude/skills/campusmate-ios26-27-expo58/` — Apple HIG, iOS 26–27.
- `.claude/skills/campusmate-android-material3-expo58/` — Google Material 3 Expressive, Android 13–16+ and adaptive devices.

Install by extracting this ZIP **at the repository root**; retain the `.claude` directory. Run Claude inside the repository and ask it to use the relevant skill(s). Do not install SDK 58 or modify the backend automatically.

Standalone `/mnt/data/skills.md` mirrors both design guides for users who prefer a single Markdown file.

Official docs must be rechecked at implementation time; some APIs and release status may change.
