# การส่งรูป สถานะออนไลน์ และการตั้งค่า — 23 ตุลาคม 2026

## ผลงานที่เชื่อมแล้ว

- แชตส่วนตัวบน iOS/Android และแชตกลุ่มบน Rust ใช้คิวส่งรูปที่อยู่เหนือหน้าห้องสนทนา รูปปรากฏจากไฟล์ในเครื่องทันทีหลังยืนยันส่ง พร้อมสถานะบนรูป ระหว่างส่งยังพิมพ์ข้อความได้
- ย่อและแปลง JPEG ก่อนเข้ารหัสไฟล์ เพื่อลดงาน JavaScript และขนาดอัปโหลด ใช้เปอร์เซ็นต์จากจำนวนไบต์ที่ระบบส่งจริง ไม่แสดงว่าส่งสำเร็จก่อนขั้นตอนข้อความรับรายการ
- เก็บคิวแยกตามบัญชี ข้อมูลคิวเข้ารหัสและไฟล์ที่เตรียมส่งอยู่ในพื้นที่ส่วนตัวของแอป ออกจากห้องได้ และกู้คิวหลังเปิดแอปใหม่ได้ เมื่อออฟไลน์คิวรอการเชื่อมต่อ รูปที่ล้มเหลวยังคงอยู่พร้อมลองใหม่/ลบ
- อัปโหลดพร้อมกันไม่เกินสองไฟล์ แต่ส่งข้อความตามลำดับการเลือกรูปในแต่ละห้อง ใช้ ID เดิม และเก็บ nonce/ciphertext สำหรับการลองส่งข้อความซ้ำ จึงรองรับกรณีไม่ทราบว่าเซิร์ฟเวอร์รับคำขอไปแล้วหรือยัง
- รูปที่ถูกระบบตรวจสอบปฏิเสธไม่ถูกส่ง และไม่มีปุ่มลองซ้ำสำหรับรูปที่ถูกบล็อก การเข้ารหัสและตรวจสอบรูปยังใช้ระบบเดิม
- รูปโปรไฟล์แสดงไฟล์ที่เลือกและสถานะบนช่องรูป ลดการบีบอัดซ้ำ อัปโหลดดิบของ Rust มีเวลาสิ้นสุดการรอ การเผยแพร่รูปหลักยังต้องผ่านขั้นตอนยืนยันเดิม

## ตรวจรายการตั้งค่า

| เมนู | การทำงาน |
| --- | --- |
| ธีมตามระบบ/สว่าง/มืด | บันทึกกับบัญชี แคชในเครื่อง และติดตามการเปลี่ยนจากอุปกรณ์อื่น |
| สถานะออนไลน์ | heartbeat ผูกกับ session จริง หมดอายุใน 90 วินาที ตรวจอายุจากเวลาของเซิร์ฟเวอร์ ออกจากแอปทำให้เฉพาะอุปกรณ์นั้นหยุดออนไลน์ |
| ซ่อนสถานะ | หลังบ้านซ่อนทั้งออนไลน์และเวลาที่ใช้งานล่าสุด หากฝ่ายใดฝ่ายหนึ่งปิด ผู้ที่ถูกบล็อกไม่เห็นสถานะ |
| เล่นวิดีโออัตโนมัติ | always/Wi-Fi/never ใช้กับตัวอย่างวิดีโอจริง การแตะเล่นเองยังทำได้ |
| ปิดเสียงวิดีโออัตโนมัติ | ใช้กับการเริ่มเล่นตัวอย่างอัตโนมัติ แยกจากการเลือกปิดเสียงในไฟล์ที่จะส่ง |
| ชื่อผู้ใช้ | ตรวจรูปแบบและความซ้ำที่เซิร์ฟเวอร์ บันทึก/ล้างได้ ไม่สัญญาว่ามีหน้าเว็บสาธารณะหรือค้นหาด้วยชื่อแล้ว |
| Push | ตรวจสิทธิ์ OS ลงทะเบียน token กับหลังบ้านที่เลือกอยู่ บันทึกการเปิด/ปิดระดับบัญชี และตรวจสิทธิ์อีกครั้งก่อนส่งจริง |
| ประกาศ CampusMate | ใช้สวิตช์จริงทั้งตัวแสดงประกาศขณะเปิดแอปและตัวส่ง Push |
| SMS/อีเมลข่าวสาร | ซ่อนจากรายการช่องทางที่เปิดใช้งาน ไม่สร้างสวิตช์ที่ไม่มีระบบส่ง อีเมลยืนยันบัญชี/กู้รหัสผ่านยังใช้ระบบบัญชีเดิม |
| การมองเห็น/ซ่อนตัว/การจับคู่ | ใช้ API และสิทธิ์สมาชิกเดิม ทางเข้ายังครบ ปรับคำเรียงลำดับให้ตรงกับเวลาที่อัปเดตโปรไฟล์ |
| บัญชีที่บล็อก | มีหน้าจัดการจริง ยืนยันก่อนเลิกบล็อก และรอหลังบ้านสำเร็จก่อนเปลี่ยนรายการ |
| ข้อมูลบนอุปกรณ์ | ล้างแคชภาพของ Expo Image จริงเมื่อยืนยัน ไม่ล้างบัญชีหรือคิวรูปที่รอส่ง |
| บัญชี/ความปลอดภัย/กฎหมาย/ช่วยเหลือ/ออกจากระบบ | คงเส้นทางและระบบเดิม ติดต่อทีมงานเปิดแอปอีเมลให้ผู้ใช้ตรวจและส่งเอง |

ชื่อค่าที่เคยบันทึกไม่เข้า เช่น `autoplayWifiOnly` และ `notify_push` ถูกแทนด้วยโครงสร้างกลาง ตัวตรวจค่าปฏิเสธชื่อที่ไม่รองรับ การตั้งค่าใหม่บันทึกหลังบ้านก่อนยืนยันผลและส่งการเปลี่ยนแปลงให้เครื่องอื่น ไม่มีการรายงานว่าบันทึกแล้วเมื่อ API ล้มเหลว
